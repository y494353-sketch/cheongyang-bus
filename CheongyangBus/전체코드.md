Kotlin · XML Layout · Material Design 3 · minSdk 24

Android Studio에서 프로젝트 폴더를 여는 방식이 가장 간단합니다. 새 프로젝트에 복사할 경우 패키지를 `com.example.cheongyangbus`로 맞추고 아래 파일을 각각 표시된 경로에 넣으세요. 생성되는 Binding 클래스는 직접 작성하지 않습니다.

package com.example.cheongyangbus

import android.view.View
import androidx.appcompat.app.AppCompatActivity
import androidx.core.view.ViewCompat
import androidx.core.view.WindowCompat
import androidx.core.view.WindowInsetsCompat
import com.google.android.material.appbar.MaterialToolbar

// 공통 처리만 모아 둡니다. 각 화면의 기능은 해당 Activity에 작성합니다.
open class BaseActivity : AppCompatActivity() {
    protected fun prepareScreen(root: View, toolbar: MaterialToolbar? = null) {
        WindowCompat.setDecorFitsSystemWindows(window, false)
        WindowCompat.getInsetsController(window, root).isAppearanceLightStatusBars = true
        WindowCompat.getInsetsController(window, root).isAppearanceLightNavigationBars = true
        ViewCompat.setOnApplyWindowInsetsListener(root) { view, insets ->
            val safe = insets.getInsets(WindowInsetsCompat.Type.systemBars() or
                WindowInsetsCompat.Type.displayCutout() or WindowInsetsCompat.Type.ime())
            view.setPadding(safe.left, safe.top, safe.right, safe.bottom)
            insets
        }
        ViewCompat.requestApplyInsets(root)
        toolbar?.setNavigationOnClickListener { finish() }
    }
}

data class BusTime(
    val origin: String,
    val destination: String,
    val departure: String,
    val arrival: String,
    val duration: String = "1시간 20분",
    val status: String = "운행예정"
) {

        putExtra("arrival", arrival)

        putExtra("status", status)

            intent.getStringExtra("origin") ?: "청양",
            intent.getStringExtra("destination") ?: "대전",

            intent.getStringExtra("arrival") ?: "10:20",

## 실행 안내

# 청양버스

Kotlin + XML + Material Design 3 기반의 7개 화면 UI 프로젝트입니다. Compose는 사용하지 않습니다.

## Android Studio에서 실행
1. 압축을 풀고 Android Studio의 **Open**으로 `CheongyangBus` 폴더를 엽니다.
2. SDK Manager에서 **Android SDK Platform 35**를 설치합니다.
3. Gradle JDK를 **17** 또는 **21**로 지정합니다. AGP 8.9.1 / Gradle 8.11.1 조합입니다.
4. Gradle Sync를 완료하고 API 24 이상 에뮬레이터 또는 기기에서 app을 실행합니다.
5. 로그인 버튼은 입력 없이도 메인 화면으로 이동합니다.

처음 동기화할 때 의존성과 Gradle을 내려받기 위한 인터넷 연결이 필요합니다. 앱 자체는 네트워크 권한이 없으며 서버·DB·API를 사용하지 않습니다.

## 구현된 흐름
로그인 → 메인 → 버스 조회 → 조회 결과 → 버스 상세정보
메인 → 즐겨찾기 → 버스 상세정보
메인 → 내 정보 → 즐겨찾기 / 알림 안내 / 로그아웃

도착지 카드는 청양 → 대전, 출발지 카드는 대전 → 청양으로 초기화됩니다. 두 지역 모두 변경할 수 있습니다. 같은 지역을 선택하면 안내 문구를 표시합니다.

## 예시 데이터와 범위
- 조회일은 요청에 맞춰 2026.09.30으로 고정했습니다.
- 모든 지역 조합은 동일한 5개 예시 시간표를 사용합니다. 실제 운행 상태나 소요시간을 의미하지 않습니다.
- 즐겨찾기에는 청양 → 대전, 청양 → 서울을 예시로 넣었습니다. 상세 화면에서 추가·해제할 수 있습니다.
- 즐겨찾기·최근 검색·알림 선택은 메모리에만 유지됩니다. 앱 프로세스가 종료되면 초기화됩니다.
- 출발 알림 버튼은 선택 UI만 제공합니다. 실제 알림 예약이나 권한 요청은 하지 않습니다.
- 로그아웃하면 화면 스택을 비워 로그인 화면으로 돌아갑니다.
- 세로 화면을 기본으로 하며, 스크롤 및 시스템 표시줄·키보드 여백을 처리했습니다.
