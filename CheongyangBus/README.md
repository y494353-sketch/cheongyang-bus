# 청양버스

Kotlin + XML + Material Design 3 기반의 7개 화면 UI 프로젝트입니다. Compose는 사용하지 않습니다.

## Android Studio에서 실행
1. 압축을 풀고 Android Studio의 **Open**으로 `CheongyangBus` 폴더를 엽니다.
2. SDK Manager에서 **Android SDK Platform 35**를 설치합니다.
3. Gradle JDK를 **17** 또는 **21**로 지정합니다. AGP 8.9.1 / Gradle 8.11.1 조합입니다.
4. Gradle Sync를 완료하고 API 24 이상 에뮬레이터 또는 기기에서 app을 실행합니다.
5. 로그인 버튼은 입력 없이도 메인 화면으로 이동합니다.

처음 동기화할 때 의존성과 Gradle을 내려받기 위한 인터넷 연결이 필요합니다. 앱 자체는 네트워크 권한이 없으며 서버·DB·API를 사용하지 않습니다.

## 구현된 흐름
로그인 → 메인 → 버스 조회 → 조회 결과 → 버스 상세정보
메인 → 즐겨찾기 → 버스 상세정보
메인 → 내 정보 → 즐겨찾기 / 알림 안내 / 로그아웃

도착지 카드는 청양 → 대전, 출발지 카드는 대전 → 청양으로 초기화됩니다. 두 지역 모두 변경할 수 있습니다. 같은 지역을 선택하면 안내 문구를 표시합니다.

## 예시 데이터와 범위
- 조회일은 요청에 맞춰 2026.09.30으로 고정했습니다.
- 모든 지역 조합은 동일한 5개 예시 시간표를 사용합니다. 실제 운행 상태나 소요시간을 의미하지 않습니다.
- 즐겨찾기에는 청양 → 대전, 청양 → 서울을 예시로 넣었습니다. 상세 화면에서 추가·해제할 수 있습니다.
- 즐겨찾기·최근 검색·알림 선택은 메모리에만 유지됩니다. 앱 프로세스가 종료되면 초기화됩니다.
- 출발 알림 버튼은 선택 UI만 제공합니다. 실제 알림 예약이나 권한 요청은 하지 않습니다.
- 로그아웃하면 화면 스택을 비워 로그인 화면으로 돌아갑니다.
- 세로 화면을 기본으로 하며, 스크롤 및 시스템 표시줄·키보드 여백을 처리했습니다.

## 코드 읽는 순서
`전체코드.md`에 프로젝트 구조, Gradle 설정, colors.xml, strings.xml, themes.xml, 전체 XML, 전체 Kotlin Activity, RecyclerView Adapter 및 데이터, Manifest 순서로 전체 코드를 수록했습니다. 각 코드 위에 파일 경로를 표시했습니다.

## 나중에 기능을 추가할 위치
- 로그인 연동: LoginActivity
- 시간표 API 연결: DemoData.schedule 호출 부분
- 즐겨찾기 영구 저장: DemoData.favorites
- 실제 알림 예약: BusDetailActivity의 alarmButton 클릭 처리

공통 여백 처리는 BaseActivity, 화면 참조는 View Binding을 사용합니다. 복잡한 아키텍처나 별도의 의존성 주입 프레임워크는 사용하지 않습니다.

## 수동 확인 순서
1. 빈 입력 로그인 → 메인 진입
2. 두 지역 선택 → 5개 시간표 표시 → 선택한 시각의 상세 화면
3. 같은 지역 선택 → 조회 방지 안내
4. 즐겨찾기 추가·해제 → 즐겨찾기 목록 반영
5. 모든 즐겨찾기 해제 → 빈 목록 안내
6. 출발 알림 선택·해제 → 안내 및 버튼 문구 변경
7. 내 정보 → 로그아웃 → 뒤로가기로 메인에 돌아가지 않음
8. 작은 화면, 큰 글꼴, 키보드 표시 상태에서 스크롤 확인
